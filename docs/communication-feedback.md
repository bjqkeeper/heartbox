# 沟通机制改进意见

记录日期：2026-11-01

## 当前判断

定向信封和约时解封可以降低当面开口的压力，并给收信人留出消化情绪的时间。当前机制更容易促成「说出来」，但不一定能帮助双方把分歧谈明白。

## 当前机制的风险

- 写信人因「赞同」获得较高积分，可能把沟通变成争取认同，也会给收信人带来迎合压力。
- 「无感」容易被理解为否定倾诉者的感受。
- 三个固定按钮没有给收信人解释、提问或继续对话的空间。

## 下一版的候选改进

1. 将回应选项调整为「我理解你的感受 / 我需要时间 / 我有不同看法」，让回应表达阅读后的状态，而非对写信人判对错。
2. 允许收信人自愿补充一句回复；「我需要时间」允许稍后继续回应，不强制即时表态。
3. 重新设计积分：鼓励认真表达与回应，不因「赞同」给出更高分。具体计分方式在用户测试后确定。

这些是待验证的产品方向，当前线上版本仍保留「赞同 / 无感 / 不认同」及可配置积分规则。
