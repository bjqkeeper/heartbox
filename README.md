# 心事信箱（内测版）

一个面向朋友和恋人的定时信封网站。当前使用 Sites 托管、ChatGPT 登录和 Cloudflare D1 持久化。

## 已实现

- 创建朋友组或双人组，使用 8 位邀请码加入。双人组最多 2 人。
- 每封信只寄给组内一位成员；每天或每周按中国标准时间定时解封。
- 解封前服务端不返回正文；收信人以外的人不能读取来信。
- 收信人可选赞同、无感、不认同；写信人按投递时的分值获得 3/1/0 分（组设置可修改）。一封信只能回应一次。
- 周/月周期积分与累计积分、组内解封设置、匿名显示选项。
- 每 7 天对同一收信人最多投递 3 封，防止密集投递。

## 本地开发

需要 Node.js 22.13+。安装依赖后运行 `npm run db:generate`、`npm run build`，再按 Sites starter 的 D1 本地迁移说明应用 `drizzle/` 中的 SQL。`npm run dev` 提供带本地模拟登录的开发预览。

## 权限规则

`/api/dashboard` 仅查询当前用户所在的组。收件箱只查询当前用户为收信人的信，未解封时响应中不包含正文。寄件箱只查询当前用户写的信。投递和回应都在服务端检查组成员、收信人及解封时间。建组人只能改设置，不能查看其他成员的信。

## 公开内测前仍需完成

当前 Site 默认仅所有者可访问，因此邀请码暂不能让朋友进入。开放真实成员前，需要确认站点访问范围，补齐举报、退出组、内容删除和账号注销流程，并做更完整的滥用与隐私测试。当前为初步开发版本，不应在未补齐这些流程时公开运营。
